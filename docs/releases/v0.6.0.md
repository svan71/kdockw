# KDockW 0.6.0 — Release notes

KDockW 0.6.0 adds built-in dock items and an application launcher with three distinct layouts.

## Added

- Manage separators and fixed spacers, including their size, visibility, order, and position at the start, center, or end of the dock.
- **macOS Launchpad:** search and browse apps in a grid with saved folders.
- **Windows Start:** use pinned apps, search, and a full app list.
- **KDE Hierarchical:** browse the system's categories and nested application menu without changing it.
- Use keyboard navigation and favorites, save the chosen layout, or import Plasma favorites once without changing Plasma settings.
- Choose a style-specific launcher icon or save a custom icon.
- Add one Launcher in new setups because its style and favorites are shared; existing duplicates are preserved and can be removed manually.

## Improved

- Place built-in items among pinned apps without changing how running tasks and Folder Stacks work.
- Keep the built-in separator aligned with the standard task separator.
- Adapt launcher windows to available screen space and KDE colors and icons.
- Close launcher popups with Escape or an outside click.

## Fixed

- Fixed a crash when creating a Launchpad folder.
- Open the widget manager from the dock context menu, even when all built-in items have been removed.
- Keep apps, folders, and navigation controls visible in each launcher layout.
- Keep widget manager controls readable in narrow and scaled windows.
- Refresh one task's icon without reloading icons for every other task.

The source release supports KDE Plasma 6 on Wayland and packages Debian 13, Ubuntu 26.04 LTS, and Fedora 45.

# KDockW 0.7.0 — Release notes

KDockW 0.7.0 adds an integrated MPRIS2 media player to the KDE Plasma Wayland dock.

## Media player

- Choose Compact, Controls, or Expanded presentation in the dock.
- Show the active media session automatically or select a player when several are available.
- View track title, artist, artwork, and playback progress.
- Control playback from the dock or its interactive popup, including previous, play/pause, next, seek, and volume where supported by the player.
- Keep the popup and dock magnification responsive while moving between media controls, application previews, and other dock items.

KDockW 0.7.0 supports KDE Plasma 6 on Wayland. The release package targets are Debian 13, Ubuntu 26.04 LTS, and Fedora 45.

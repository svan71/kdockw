# KDockW 0.6.0 release notes

KDockW 0.6.0 adds persistent built-in dock widgets and a KDE-native application launcher with three switchable styles.

## Built-in Dock Widgets

- Add and manage separators and fixed spacers from the dock's widget manager.
- Set widget size, visibility, order, and placement at the start, center, or end of the dock.
- Drag built-in widgets among pinned entries while keeping running TaskManager rows outside widget ordering.
- Keep widget sizing and Spring Magnification behavior consistent across all four dock edges.

## Application Launcher

- **macOS Launchpad:** browse a paginated app grid, search the catalog, and organize applications into persistent folders.
- **Windows Start:** use a pinned-app home, a separate full alphabetical list, letter navigation, search, and favorites.
- **KDE Hierarchical:** browse the original KService/XDG Menu categories and nested sections, with category previews and a shared Favorites folder.
- Import Plasma favorites once into an empty Windows Start favorites list without changing Plasma settings. Windows Start and KDE Hierarchical share their KDockW favorites.
- Use the KDE icon theme and KDockW/Kirigami colors, with distinct default style icons and a saved user icon override.
- Open adaptive popups with keyboard navigation, themed menus, and dismissal on Escape or outside click.
- Keep Launchpad folders and layout in KDockW settings; system desktop entries and the XDG menu remain unchanged.

## TaskManager and compatibility

- Refresh an individual task's icon without invalidating icons for every task.
- Keep the built-in separator aligned with the TaskManager separator as task rows move.
- Preserve DockEntries migration and compatibility with existing pinned apps and Folder Stacks.

The source release supports KDE Plasma 6 on Wayland and provides packages for Debian 13, Ubuntu 26.04 LTS, and Fedora 45.

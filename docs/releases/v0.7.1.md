# KDockW 0.7.1 — Release notes

KDockW 0.7.1 improves shadow controls, media volume routing, and selecting a
specific window from Window Preview.

## Shadow settings

- Adjust shadow direction smoothly with a 0–359° slider and precise numeric
  input.
- Keep live preview responsive while settings are saved reliably.

## Media volume

- Choose Automatic, Player Volume Only, or Computer Volume control.
- Automatic uses the selected player's MPRIS volume when it is supported and
  falls back to the default computer output only after a successful but ignored
  player-volume request.
- Existing v0.7.0 settings migrate to Player Volume Only, preserving their
  previous behavior.

## Window Preview

- Activate the exact window selected by its thumbnail, including a chosen
  window in a group.

KDockW 0.7.1 supports KDE Plasma 6 on Wayland. The required package targets are
Debian 13, Ubuntu 26.04 LTS, and Fedora 45.

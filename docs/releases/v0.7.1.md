# KDockW 0.7.1 — Release notes

KDockW 0.7.1 makes shadow settings easier to adjust, adds flexible media volume control, and improves window selection from previews.

## Added

- Choose Automatic, Player Volume Only, or Computer Volume in the media widget.
- In Automatic mode, use player volume when supported and switch to the computer's default sound output if the player cannot change its own volume.
- Existing v0.7.0 settings remain in Player Volume Only mode; new configurations use Automatic.

## Improved

- Adjust shadow direction with a live preview, a smooth 0–359° slider, or precise numeric input.

## Fixed

- Activate the exact window selected in Window Preview, including a specific window in a group.

KDockW 0.7.1 supports KDE Plasma 6 on Wayland. Required package targets are Debian 13, Ubuntu 26.04 LTS, and Fedora 45.

# KDockW 0.7.0 — Release notes

KDockW 0.7.0 adds a media player to the KDE Plasma dock.

## Added

- Choose Compact, Controls, or Expanded presentation.
- Show the active player automatically or select one when several are available.
- View track title, artist, artwork, and playback progress.
- Control playback from the dock or its popup, including previous, play/pause, next, seek, and volume when supported by the player.
- Choose when the widget appears, whether to show artwork and paused players, how long stopped players remain visible, and how the popup opens.

## Improved

- Set the Expanded widget width from 200 to 300 logical pixels in 5-pixel steps. Long track details shorten to fit instead of widening the widget.
- Keep playback controls usable while leaving room for neighboring dock icons.

## Fixed

- Open the media popup across the full widget, including its playback buttons, and keep it available while moving between the widget and popup.
- Pass magnification smoothly between the media widget, its popup, and neighboring dock icons.
- Refresh running-window indicators when windows in a grouped app are opened or closed.

KDockW 0.7.0 supports KDE Plasma 6 on Wayland. Required package targets are Debian 13, Ubuntu 26.04 LTS, and Fedora 45.

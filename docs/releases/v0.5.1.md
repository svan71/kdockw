# KDockW 0.5.1 — Release notes

KDockW 0.5.1 gives maximized windows more room, clarifies application menus, and adds Fedora 45 packages.

## Added

- Set a saved 0–20 px gap between the dock and maximized windows. Changes apply immediately on all four dock edges.
- Added Fedora 45 / Qt 6.11 packages.

## Improved

- Grouped KDockW actions in their own submenu while keeping application actions, Desktop Actions, pinning, and new-instance commands available.
- Separated closing a window or app group from quitting KDockW.

## Fixed

- Kept the dock's screen area reserved after unlock if its position and size have not changed.
- Kept pinned app names and active-window selection current on Qt 6.11, including windows on other screens.
